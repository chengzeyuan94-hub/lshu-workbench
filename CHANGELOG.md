# Changelog

## 0.1.0 — 2026-08-25

First public-source baseline.

- Local dashboard with Today, Todos, Finance, Content Performance, Hotspots, Knowledge, Scan and Settings.
- Four-source today overview for Things, Feishu, Apple Calendar and desktop evidence.
- AI-assisted local day plan limited to five focus tasks, rendered as a printable receipt.
- Xiaohongshu creator metrics and note performance adapters.
- Hotspot collection, single/batch Moments generation and persistent history.
- Read-only MoneyCats backup analysis for weekly, monthly and yearly cash flow.
- macOS-first local setup scripts, diagnostics and privacy release gate.
- Public package defaults every local connector and scheduler to off.

This version intentionally does not include credentials, local databases, logs, personal work profiles, acceptance screenshots or external knowledge-base data.
